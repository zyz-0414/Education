# 第 7 周志愿表编辑器

## 完成范围

- 首页工作台已新增志愿表编辑器；
- 推荐结果中的院校专业组可以加入志愿表；
- 已加入的院校专业组会禁用重复加入；
- 志愿表最多保留 45 个院校专业组；
- 志愿表支持删除单条志愿；
- 志愿表支持上移、下移，并在移动后自动重算顺序；
- 志愿表展示冲、稳、保、过保数量和建议区间；
- 保和过保不足时显示强提示；
- 冲刺志愿过多、稳妥志愿偏少、高危项进入表内时显示提示；
- 方案可以保存到浏览器本地存储，刷新页面后恢复。

第 7 周只完成志愿表编辑和本地方案保存，不做第 8 周的风险检测报告页面。

## 比例检查

当前沿用算法文档中的第一版默认组合：

| 档位 | 建议数量 |
| --- | --- |
| 冲 | 8-12 |
| 稳 | 20-25 |
| 保 | 8-12 |
| 过保 | 1-3 |

编辑器会实时统计志愿表内各档位数量。保底数量按 `保 + 过保` 计算，少于 8 个时显示保底不足提示。

## 保存口径

方案保存使用浏览器 `localStorage`：

- key：`gaokao-volunteer-plan-v1`
- 内容：保存时间、考生画像快照、志愿表条目；
- 适用范围：本机本浏览器内恢复草稿；
- 不包含：账号系统、多人共享、服务端持久化。

服务端持久化和完整风险报告属于后续版本范围。

## 验收命令

```bash
npm run test:week7
npm run verify:week7
```

`verify:week7` 会先执行第 0-6 周验收，再运行第 7 周志愿表规则测试。
