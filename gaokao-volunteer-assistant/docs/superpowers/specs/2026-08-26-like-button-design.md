# 点赞按钮设计

## 范围

在首页左侧工作台标题区域增加一个单次点赞控件。控件默认显示空心爱心和 `276`；点击后显示实心爱心和 `277`；再次点击恢复默认状态。

## 界面与交互

- 控件与“使用说明”并列，位于“皖志愿”标题的操作区。
- 使用 Lucide 的 `Heart` 图标，未点赞时为描边，已点赞时为红色填充。
- 控件使用按钮语义、中文 `aria-label` 与悬停提示，键盘可触发。
- 数字不受长文本或响应式布局影响；窄屏时随同标题操作区正常换行。

## 状态与数据

- 在 `CandidateProfileWorkspace` 中维护 `isLiked` 布尔状态。
- 已展示的计数由基数 `276` 加上点赞状态计算，不调用 API，也不写入数据库或本地存储。
- 页面刷新后恢复未点赞和 `276`，符合一次会话内的轻量反馈需求。
