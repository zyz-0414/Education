# 推荐算法草案

## 原则

1. 先硬规则过滤，再做推荐排序。
2. 以位次为核心，不以分数为核心。
3. 第一版推荐单位是院校专业组。
4. 历史/物理科目轨道必须先匹配，再比较院校专业组位次。
5. 数据不足时标低置信度。
6. 推荐理由必须来自结构化数据。

## 第一版参考位次

```text
预测参考位次 =
  2025 专业组最低位次 * 0.5
+ 2024 专业组最低位次 * 0.35
+ 2023 旧文理科院校最低位次 * 0.15
+ 招生计划变化修正
+ 波动风险修正
```

2023 年安徽尚未实行新高考专业组，理科映射为物理类，文科映射为历史类，再选科目按不限处理。2023 数据只作为院校级旧口径参考展示和低权重建模，不视为专业组线。如果近三年不完整，或改革后专业组历史不足两年，推荐项标为低置信度。新增、拆分、合并或名称变化的专业组进入人工确认。

## 冲稳保分档

```text
rank_gap_ratio = (用户位次 - 预测参考位次) / 预测参考位次
```

| 档位 | 初始规则 |
| --- | --- |
| 冲 | 0% 到 +8% |
| 稳 | -12% 到 0% |
| 保 | -30% 到 -12% |
| 过保 | 小于 -30% |
| 高危 | 大于 +8% |

阈值需要用安徽 2024、2025 数据回测后修正。

## 默认志愿组合

| 档位 | 数量建议 |
| --- | --- |
| 冲 | 8-12 |
| 稳 | 20-25 |
| 保 | 8-12 |
| 过保 | 1-3 |

保底志愿必须在用户可接受范围内。如果保底不足，系统必须提示。

- 已实现近三年最低位次加权、招生计划变化修正和位次波动保守修正，其中 2023 为旧文理科院校级参考。
- 已实现冲、稳、保、过保、高危分档。

- 已实现低置信度标记，覆盖历史数据不足、OCR 样例、招生计划样例、缺少计划明细和波动过大。
- 正式推荐默认要求有当年招生计划明细；OCR 历史投档样例只用于排查和解释，不默认进入正式推荐。

## 第 7 周志愿表状态

- 首页工作台已新增志愿表编辑器。
- 推荐结果可加入志愿表，并支持删除、上移、下移。
- 志愿表限制最多 45 个院校专业组。
- 编辑器会按冲、稳、保、过保统计数量，并提示保底不足。
- 方案保存到浏览器本地存储，服务端持久化留到后续版本。

## 第 8 周风险报告状态

- 已新增志愿方案风险报告模块，输入为当前志愿表条目、考生画像和偏好快照。
- 滑档风险覆盖高危项进入方案和冲刺数量超过建议上限。
- 保底不足按保 + 过保少于 8 个触发。
- 专业组排斥专业按用户排斥方向扫描专业名称和备注。
- 高学费风险覆盖超预算、20000 元/年及以上、备注含高学费或合作办学提示。
- 低置信度风险汇总推荐模型输出的置信度原因。
- 首页展示方案报告摘要，`/report` 展示可解释方案报告。

## 第 9 周上线状态

- 页面文案已从开发周次标签收口为“安徽高考志愿助手”正式演示版。

## 2026-06-02 推荐调优记录

- 候选池：内部候选专业组上限提升到 5000，再由推荐层按分档配额选出默认 45 条，避免初始排序截断造成推荐数量不足。
- 分档：正向位次差使用自适应冲刺阈值。比例上限为 `12%`，同时按考生位次段提供绝对缓冲：前 2000 名为 350 位，前 5000 名为 600 位，其余为 1000 位。超过该范围才进入高危。
- 负向位次差：`-12%` 内为稳，超过后进入保；保档同时保留 10000 位绝对缓冲，超过后进入过保。
- 推荐配额：均衡模式默认约为高危 4、冲 10、稳 18、保 10、过保 3；关闭高危时其名额转入冲，关闭过保时其名额转入保。
- 展示顺序：最终列表按 `高危 -> 冲 -> 稳 -> 保 -> 过保` 展示，同一档内按参考位次从小到大排列。候选池挑选仍按可行性和位次接近程度排序，避免为了展示顺序选入过难项目。
- 用户控制：高危冲刺和过保兜底均作为显式开关暴露，默认不纳入高危，默认保留少量过保兜底。

## 2026-06-02 近三年位次升级

- 数据：清洗接入 2023 安徽一分一段和改革前院校投档线。2023 理科映射物理类，文科映射历史类，生成合成旧口径组号 `000` 仅用于数据库外键。
- 匹配：2024、2025 优先按院校专业组精确匹配；找不到同组历史时，按同院校、同科类、同选科要求的相近专业组补充，并标注“同院校专业组参考”。2023 按院校名称快照匹配到当前专业组，并标注“旧文理科院校线”。
- 建模：三年权重默认约为 2025 `0.5`、2024 `0.35`、2023 `0.15`，缺失年份时按可用数据归一化。
- 展示：推荐表格和右侧详情面板均显示近三年参考位次，2023 明确显示旧口径说明。
