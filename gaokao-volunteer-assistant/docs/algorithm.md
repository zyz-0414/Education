# 推荐算法草案

## 原则

1. 先硬规则过滤，再做推荐排序。
2. 以位次为核心，不以分数为核心。
3. 第一版推荐单位是院校专业组。
4. 历史/物理科目轨道必须先匹配，再比较院校专业组位次。
5. 数据不足时标低置信度。
6. 推荐理由必须来自结构化数据。

## 第一版参考位次

```text
预测参考位次 =
  2025 最低位次 * 0.6
+ 2024 最低位次 * 0.4
+ 招生计划变化修正
+ 波动风险修正
```

如果只有一年数据，使用单年数据并标为低置信度。新增、拆分、合并或名称变化的专业组进入人工确认。

## 冲稳保分档

```text
rank_gap_ratio = (用户位次 - 预测参考位次) / 预测参考位次
```

| 档位 | 初始规则 |
| --- | --- |
| 冲 | 0% 到 +8% |
| 稳 | -12% 到 0% |
| 保 | -30% 到 -12% |
| 过保 | 小于 -30% |
| 高危 | 大于 +8% |

阈值需要用安徽 2024、2025 数据回测后修正。

## 默认志愿组合

| 档位 | 数量建议 |
| --- | --- |
| 冲 | 8-12 |
| 稳 | 20-25 |
| 保 | 8-12 |
| 过保 | 1-3 |

保底志愿必须在用户可接受范围内。如果保底不足，系统必须提示。
