# 第 8 周风险检测和报告

## 完成范围

- 已新增志愿方案风险报告核心模块；
- 已检测滑档风险：
  - 高危项进入方案；
  - 冲刺数量超过建议上限；
- 已检测保底不足：
  - 保和过保合计少于 8 个时标为重点风险；
- 已检测专业组排斥专业：
  - 根据考生排斥方向扫描专业名称和备注；
  - 同时兼容推荐项中的排斥专业惩罚理由；
- 已检测高学费：
  - 超过用户学费上限；
  - 学费达到 20000 元/年及以上；
  - 备注含高学费、较高学费、中外合作或合作办学；
- 已检测低置信度：
  - 汇总推荐模型暴露的历史数据不足、波动大、计划缺失等原因；
- 首页工作台已新增简版方案报告摘要；
- 风险证据数量较多时不再截断，工作台和报告页均使用滚动区域展示完整证据；
- 已新增 `/report` 简版报告页面，从浏览器本地保存的志愿方案生成可解释报告；
- 已新增 PDF 导出：
  - 志愿表编辑器可导出“志愿表 + 简版分析报告”；
  - `/report` 页面可导出同口径 PDF；
  - PDF 内容包含考生画像、志愿表、风险检测、调整建议和数据口径。

第 8 周只完成风险检测、简版网页报告和本地 PDF 导出，不做账号系统、服务端报告持久化和线上部署。

## 报告结构

首页工作台中的报告摘要展示：

- 方案状态；
- 考生画像；
- 志愿总数、冲高数量、保底数量、最高学费；
- 风险检测清单；
- 调整建议；
- 算法版本和数据版本；
- PDF 导出入口。

`/report` 页面展示：

- 第 8 周风险检测结论；
- 考生画像与保存时间；
- 志愿总数、保底数量、低置信度数量；
- 滑档、保底不足、排斥专业、高学费、低置信度风险证据；
- 调整建议和数据口径说明；
- PDF 导出入口。

## 检测口径

| 风险 | 触发条件 | 严重度 |
| --- | --- | --- |
| 滑档风险 | 高危项进入方案 | 重点调整 |
| 滑档风险 | 冲刺数量超过 12 个 | 需要复核 |
| 保底不足 | 保 + 过保少于 8 个 | 重点调整 |
| 专业组排斥专业 | 专业名称或备注命中排斥方向 | 重点调整 |
| 高学费 | 超预算、达到高学费阈值或备注提示合作办学 | 需要复核 |
| 低置信度 | 推荐项 `lowConfidence=true` | 需要复核 |

## 本地保存

方案仍使用浏览器 `localStorage`：

- key：`gaokao-volunteer-plan-v1`
- 第 8 周保存内容新增：
  - 偏好快照；
  - 算法版本；
  - 数据版本。

旧版第 7 周草稿仍可读取，但旧草稿没有偏好和算法快照时，报告会以当前表单偏好或缺省信息生成。

## 验收命令

```bash
npm run test:week8
npm run verify:week8
```

`verify:week8` 会先执行第 0-7 周验收，再运行第 8 周风险报告规则测试。

PDF 导出依赖服务端中文字体。Windows 本机优先使用等线或黑体；部署到 Linux 时建议在 `public/fonts/` 放置可用的简体中文字体文件，例如 `NotoSansSC-Regular.otf`。
