# 项目计划基线

## 项目定位

安徽高考志愿助手是面向安徽普通类本科批考生的响应式 Web 工具。第一版只做安徽，不做全国、不做专家审核、不做支付、不做原生 App。

## 第一阶段目标

用户输入选科、分数、位次和偏好后，系统基于安徽官方公开数据、历史录取位次、招生计划和选科要求，生成冲稳保志愿建议、风险提示和可解释志愿表。

## P0 功能

1. 安徽考生建档；
2. 一分一段校验；
3. 偏好设置；
4. 数据导入脚本；
5. 选科、批次、计划硬规则过滤；
6. 冲稳保推荐；
7. 推荐解释；
8. 风险提示；
9. 志愿表编辑；
10. 响应式 UI；
11. 在线部署。
