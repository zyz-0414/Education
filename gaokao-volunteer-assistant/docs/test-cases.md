# 测试用例草案

## 规则过滤

1. 选科不满足院校专业组要求时，不进入推荐结果。
2. 当年无安徽普通本科批招生计划时，不进入推荐结果。
3. 位次低于本科批适用范围时，提示不适用当前批次。
4. 学费超过用户严格预算时过滤。
5. 专业组包含强排斥专业时，严格模式过滤，普通模式降权并提示。

## 数据清洗

1. 一分一段表必须按年份和科目轨道唯一定位分数。
2. `rank_min` 与 `rank_max` 必须能由同分人数和累计人数反推。
3. 历史科目组合和物理科目组合复用同一院校专业组号时，必须通过 `subject_track` 区分。
4. OCR 来源的投档结果必须保留原始长图文件名，并标记待人工复核。

## 推荐分档

1. 用户位次比参考位次靠后 5%，应标为冲。
2. 用户位次比参考位次靠前 8%，应标为稳。
3. 用户位次比参考位次靠前 20%，应标为保。
4. 用户位次比参考位次靠后 12%，应标为高危。
5. 只有一年历史数据时，应标为低置信度。

## 志愿表

1. 最多允许 45 个院校专业组志愿。
2. 删除志愿后顺序自动连续。
3. 上移/下移后重新检测冲稳保比例。
4. 保底不足时显示强提示。
